# CapacityMeter

Shows how many places are taken. Exposed as `role="meter"` with a readable
`aria-valuetext`. Turns amber at 80% and red when full.

## Usage

```tsx
<CapacityMeter registered={event.registeredCount} capacity={event.capacity} />
```
