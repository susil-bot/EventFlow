# EventMetaRow

Icon tile + two text lines, used on the event detail page for the schedule
and the venue.

## Usage

```tsx
<EventMetaRow icon="pin" primary={event.venue} secondary="Venue" />
<EventMetaRow
  leading={<DateBadge {...getDateBadgeParts(event)} />}
  primary={formatEventDay(event)}
  secondary={formatEventTime(event)}
/>
```
