# RegistrationItem

One row of the attendee dashboard. Must be rendered inside a `<ul>`.

## Behavior

- Active registrations show a **Registered** badge and a cancel action.
- Canceled registrations are dimmed and labelled **Registration canceled** so
  they are clearly distinguished from active ones.
- If the organizer canceled the event, an **Event canceled** badge appears and
  the cancel action is hidden.
