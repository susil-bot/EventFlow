# ReasonAction

A destructive admin action that requires a written reason. The reason is
sent to the API and stored in the admin audit log.

## Usage

```tsx
<ReasonAction
  label="Suspend"
  confirmLabel="Suspend account"
  onConfirm={(reason) => suspend(user.id, reason)}
/>
```
