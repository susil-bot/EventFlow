# AttendeeTable

Lists an event's active registrations: name, email and registration time.
Only rendered for the event's organizer — the API verifies ownership before
returning any attendee data. Render empty states with `StateView`.

## Usage

```tsx
<AttendeeTable
  attendees={data.attendees}
  caption={`Attendees for ${event.title}`}
/>
```
