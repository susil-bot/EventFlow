# ToastStack

Bottom-right notification stack used for mutation success and error messages.
Errors use `role="alert"`; others use `role="status"`. Use the `useToast()`
hook from `ToastProvider` instead of rendering this directly.

## Usage

```tsx
const toast = useToast();
toast.success("You're registered!");
toast.error(getErrorMessage(error));
```
