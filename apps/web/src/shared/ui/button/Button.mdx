# Button

Primary action control. `LinkButton` renders a router `Link` with the same
styles for navigation.

## Usage

```tsx
<Button onClick={save} isLoading={isSaving}>Save</Button>
<LinkButton to="/organizer/events/new">Add Event</LinkButton>
```

## Behavior

- `isLoading` shows a spinner, sets `aria-busy` and disables the button so a
  mutation cannot be submitted twice.
- Defaults to `type="button"`; pass `type="submit"` inside forms.
- Variant styling uses transient props (`$variant`, `$size`) so nothing
  leaks to the DOM.
