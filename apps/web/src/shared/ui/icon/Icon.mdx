# Icon

Stroke-based inline SVG icon set. Icons inherit `currentColor`, so colour is
controlled by the parent.

## Usage

```tsx
<Icon name="calendar" />
<Icon name="alert" title="Error" />
```

## Accessibility

- Decorative by default (`aria-hidden`).
- Pass `title` when the icon is the only content conveying meaning.
